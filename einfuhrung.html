    Dieses Dokument ist ein Produkt von Claude, der KI von Anthropic. Es ist eine Neufassung des Kurses „Die Sprache C# lernen, Version 3.0 mit dem .NET-3.5-Framework“, verfasst von Serge Tahé im Mai 2008, für C# 14 und die Plattform .NET 10. Es behält Gliederung, Beispiele und roten Faden des Kurses bei und aktualisiert Sprache, Bibliotheken und Werkzeuge:

    • Der Kurs von 2008 verwendete C# 3.0 und das .NET-3.5-Framework unter Windows mit Visual C# 2008 Express. Seitdem hat C# elf Hauptversionen erlebt (von C# 4.0 im Jahr 2010 bis C# 14 im Jahr 2025), und die Plattform .NET wurde komplett neu geschrieben: Sie ist heute Open Source, plattformübergreifend (Windows, Linux, macOS) und erscheint jährlich. Dieses Dokument verwendet .NET 10 (November 2025, Version mit Langzeitunterstützung) und C# 14;
    • Das Kapitel über grafische Oberflächen mit Windows Forms wurde entfernt: Heute werden Geschäftsanwendungen meist mit Weboberflächen geschrieben. Das darauf folgende Kapitel „Benutzerereignisse“ wurde zu einem Kapitel über Delegaten, Lambda-Ausdrücke und Ereignisse ohne Formulare überarbeitet;
    • Zwei Kapitel sind neu: asynchrone Programmierung ([Task]-Aufgaben und [async] / [await], 2012 mit C# 5 eingeführt) und Entity Framework Core, das objektrelationale Mapping-Werkzeug für .NET. Das Kapitel über häufig verwendete .NET-Klassen behandelt nun LINQ (der Kurs von 2008 hatte ausdrücklich darauf hingewiesen, dass er dieses Thema nicht behandelt);
    • Die Werkzeuge haben sich geändert: Der [VS Code]-Editor (oder die IDE [Visual Studio 2026]) und der Befehl [dotnet] ersetzen Visual C# 2008 Express; das Test-Framework [MSTest] ersetzt [NUnit 2]; die von [Microsoft.Extensions.DependencyInjection] bereitgestellte Dependency Injection ersetzt [Spring.NET]; das DBMS [MySQL] (bereitgestellt von [Laragon]) und der Konnektor [MySqlConnector] ersetzen SQL Server 2005 Express; die Klasse [HttpClient] ersetzt [WebClient] und [WebRequest], die veraltet sind; die mit ASP.NET Core geschriebenen REST-/JSON-Webservices ersetzen die SOAP- und [ASMX]-Webservices;
    • Was veraltet ist, wurde entfernt oder als solches gekennzeichnet, und jedes Kapitel stellt die zum Zeitpunkt der Erstellung neuesten Funktionen der Sprache und der Plattform vor.

    Dieses Dokument ist kein umfassender Kurs. Wie die Ausgabe von 2008 richtet es sich an Leser, die bereits Programmiererfahrung haben und die Grundlagen von C# erlernen möchten. Es arbeitet mit Beispielen: mehr als zweihundert Programme (fast dreihundert C#-Dateien), die meisten davon kurz und Zeile für Zeile kommentiert.

    1.1. C# und .NET von 2002 bis 2026

    C# erschien im Februar 2002 zusammen mit Microsofts Plattform .NET 1.0, mit der es eng verbunden ist. Die Plattform .NET ist eine Laufzeitumgebung ähnlich der Java Virtual Machine: Die Compiler der .NET-Sprachen (C#, F#, VB.NET) erzeugen Zwischencode (IL, „Intermediate Language“), den die virtuelle Maschine von .NET (die CLR, „Common Language Runtime“) zur Laufzeit in Maschinencode übersetzt. Alle Klassen der Plattform stehen allen .NET-Sprachen zur Verfügung.

    Im Kurs von 2008 hieß es, .NET laufe nur unter Windows, und das Projekt Mono erlaube eine eingeschränkte Nutzung unter Unix und Linux. Die Situation hat sich erheblich verändert:

    • 2016: .NET Core 1.0. Microsoft hat eine neue Implementierung von .NET veröffentlicht, die quelloffen ist (MIT-Lizenz, Code auf GitHub verfügbar) und plattformübergreifend: Windows, Linux und macOS. Das alte „.NET“-Framework (.NET Framework 4.x) wird für ältere Windows-Anwendungen weiterhin unterstützt, aber nicht mehr weiterentwickelt;
    • 2020: .NET 5. .NET Core heißt nur noch „.NET“: eine einzige Plattform für alle Einsatzzwecke (Konsole, Web, Desktop, Mobile, Cloud);
    • Seit 2020: Jedes Jahr im November erscheint eine neue Version von .NET. Versionen mit gerader Nummer (.NET 6, 8, 10) haben erweiterten Support (LTS, drei Jahre); Versionen mit ungerader Nummer (.NET 7, 9) haben Standard-Support (STS: achtzehn Monate, ab .NET 9 auf zwei Jahre verlängert). Jede Version von .NET bringt eine neue Version von C# mit;
    • November 2025: .NET 10 (LTS) und C# 14, die in diesem Dokument verwendet werden. .NET 10 wird bis November 2028 unterstützt.

    Der Kurs von 2008 stellte auch fest, dass C# im Jahr 2002 weitgehend eine Kopie von Java war und der Wechsel zwischen beiden Sprachen leichtfiel, dass sich die beiden Sprachen seither aber jeweils eigene Merkmale zugelegt haben. Der Abstand hat sich vergrößert: Im Laufe seiner Versionen hat C# Konzepte aus funktionalen Sprachen übernommen (Lambda-Ausdrücke, LINQ, Pattern Matching, Records, unveränderliche Typen), außerdem die asynchrone Programmierung ([async] / [await], die inzwischen auch JavaScript, Python und Rust übernommen haben) und ein Typsystem, das Null-Referenzen zur Kompilierzeit erkennt.

    1.2. Inhalt des Dokuments

    Dieses Dokument enthält die folgenden Kapitel:

    • Kapitel 2: Einrichtung der Entwicklungsumgebung (.NET 10 SDK, VS Code oder Visual Studio; der Befehl [dotnet]);
    • Kapitel 3: Grundlagen der Sprache (Typen, Operatoren, Kontrollanweisungen, Ausnahmen, Enumerationen, Parameterübergabe, Tupel);

    • Kapitel 6: Mehrschichtige Architekturen, Unit-Tests mit MSTest und Dependency Injection;
    • Kapitel 7: Delegaten, Lambda-Ausdrücke und Ereignisse;
    • Kapitel 8: Ausführungs-Threads und Synchronisation;
    • Kapitel 9: Asynchrone Programmierung;
    • Kapitel 10: Datenbankzugriff mit ADO.NET;
    • Kapitel 11: Entity Framework Core;
    • Kapitel 12: Webprogrammierung (TCP/IP, TCP-Clients und -Server, HTTP mit [HttpClient]);

    • Kapitel 14: Weiterführendes;
    • Anhänge: Installation von Laragon und MySQL.

    1.3. Der rote Faden: die Steuerberechnung

Verwendet wird die Steuertabelle des ursprünglichen Kurses (Einkommen 2003): Sie ist nicht mehr aktuell, genügt aber für unseren Zweck, nämlich dieselbe Anwendung auf mehrere verschiedene Arten zu schreiben. Die Ergebnisse von Kapitel 3 wurden mit der französischen Ländereinstellung (fr-FR) erzeugt, wie auf einem französischen Windows-Arbeitsplatz: Reelle Zahlen werden mit Dezimalkomma angezeigt, und Datumsangaben sind französisch. Die späteren Kapitel wurden mit der amerikanisch-englischen Ländereinstellung (en-US) ausgeführt: Dezimalpunkt, Komma als Tausendertrennzeichen, Datumsangaben im Format Monat/Tag/Jahr. Zwei Hinweise:

    • Fehlermeldungen der Plattform .NET (Meldungen von Ausnahmen) sind auf Englisch: .NET stellt für diese Meldungen keine französischen Übersetzungen bereit;
    • die Beispiele wurden unter Linux ausgeführt. Meist macht das keinen Unterschied: .NET ist plattformübergreifend. Die wenigen Unterschiede (Dateipfade mit / statt \, Zeilenenden) werden an den jeweiligen Stellen vermerkt.

    Die Ergebnisse von Multithreading-, asynchronen oder Netzwerkprogrammen sowie die gemessenen Ausführungszeiten können sich von Ausführung zu Ausführung unterscheiden: Die Kommentare konzentrieren sich auf das, was reproduzierbar ist.
