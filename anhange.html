    15. Anhänge

    15.1. DBMS und MySQL mit Laragon

    Im Jahr 2008 beschrieben die Anhänge des Kurses die Installation von SQL Server 2005 Express und MySQL 5, ihrer Verwaltungswerkzeuge (MySQL GUI Tools) und ihrer ODBC-Treiber, mit etwa dreißig Screenshots. Die Kapitel 10 und 11 dieses Dokuments verwenden ausschließlich MySQL 8, und der einfachste Weg, es unter Windows zu installieren, ist die Installation von Laragon, einer portablen Entwicklungsumgebung, die unter anderem MySQL, den grafischen Client HeidiSQL, ein vorkonfiguriertes Terminal, Apache und PHP enthält. Der Autor nutzt sie auch für seine PHP-Kurse.

    15.1.1. Installation

    Laragon kann von https://laragon.org heruntergeladen werden. Die Installation verläuft standardmäßig; Sie können den vorgeschlagenen Installationsordner ([C:\laragon]) beibehalten. Laragon stellt MySQL 8 bereit (die genaue Version hängt von der Laragon-Version ab), mit einem passwortlosen Administratorkonto ([root]) und einem Server, der auf Port 3306 des lokalen Rechners lauscht. Diese Konfiguration setzen die Beispiele in diesem Dokument voraus, in denen die Verbindungszeichenfolgen die Form haben:

    1
    Server=localhost;Port=3306;Database=dbarticles;User=root;Password=

    Wurde MySQL anders installiert, mit einem Passwort für [root], müssen Sie das Passwort bei [Password=] in den Verbindungszeichenfolgen der Beispiele ([appsettings.json]-Dateien oder Konstanten am Anfang der Programme) eintragen.

    Für ein System ohne Laragon können Sie MySQL Community Server auch von https://dev.mysql.com/downloads/mysql/ installieren oder dessen quelloffenen Abkömmling MariaDB. Die Beispiele wurden jedoch nur mit MySQL 8 getestet: Die Skripte in Kapitel 10 verwenden eine MySQL-8-spezifische Collation ([utf8mb4_0900_ai_ci]), und die Beispiele in Kapitel 11 übergeben Pomelo eine MySQL-Serverversion ([MySqlServerVersion]); bei MariaDB müssten diese beiden Punkte angepasst werden.

    15.1.2. Starten und Beenden von MySQL

    Das Hauptfenster von Laragon enthält eine Schaltfläche „Start All“, die die Server (Apache und MySQL) startet, und eine Schaltfläche „Stop“, die sie beendet. Anders als bei der 2008 beschriebenen MySQL-5-Installation ist MySQL kein Windows-Service, der beim Systemstart läuft: Es läuft nur, wenn es über Laragon gestartet wird, sodass es keine Ressourcen verbraucht, wenn es nicht benötigt wird. Über das Laragon-Menü (Rechtsklick im Fenster) lässt sich außerdem nur MySQL starten und seine Version auswählen.

    Wenn MySQL nicht läuft, scheitern die Programme der Kapitel 10 und 11 mit einer Ausnahme, die besagt, dass keine Verbindung hergestellt werden konnte („Unable to connect to any of the specified MySQL hosts“): Dies ist das Erste, was Sie bei einem Fehler prüfen sollten.

    15.1.3. Der Kommandozeilen-Client

    Die Schaltfläche Terminal in Laragon öffnet ein Terminal, in dem Laragon-Befehle verfügbar sind, darunter der MySQL-Kommandozeilenclient [mysql]. Um sich mit dem Server zu verbinden, verwenden Sie:

    1
    > mysql -u root

    Geben Sie dann SQL-Befehle ein, die mit einem Semikolon enden ([show databases;], [use dbarticles;], [select * from articles;]), und mit [exit] beenden Sie den Client. Er kann auch ein SQL-Skript ausführen, was Kapitel 10 zum Anlegen seiner Datenbanken nutzt:

    1
2
3
    > cd csharp-oct-2026\10-adonet\sql
> mysql -u root < dbarticles.sql
> mysql -u root < dbtaxes.sql

    Die Skripte erstellen ihre Datenbank bei jeder Ausführung vollständig neu: Sie können sie erneut ausführen, um die Daten nach Tests in den Anfangszustand zurückzusetzen.

    15.1.4. Der grafische Client HeidiSQL

    Die Schaltfläche Database in Laragon startet den grafischen Client HeidiSQL, der die MySQL GUI Tools von 2008 (inzwischen veraltet) ersetzt. Beim ersten Start bietet HeidiSQL eine bereits für den MySQL-Server von Laragon konfigurierte Verbindungssitzung an (Host [127.0.0.1], Benutzer [root], leeres Passwort, Port 3306); öffnen Sie diese einfach. Sie sehen:

    • links die Baumansicht der Datenbanken des Servers und ihrer Tabellen;
    • rechts Registerkarten, die die Struktur einer Tabelle, ihre Daten (die direkt bearbeitet werden können) und ein Feld zur Eingabe von SQL-Abfragen (die Registerkarte „Query“) anzeigen, wobei die Abfragen mit [F9] ausgeführt werden.

    Um mit einem Skript aus Kapitel 10 eine Datenbank zu erstellen, öffnen Sie das Skript (über das Menü „File“ mit dem Befehl „Load SQL file“) in einer Abfrage-Registerkarte und führen es dann aus ([F9]). Sie können eine Datenbank, einen Benutzer und Benutzerrechte auch über die Menüs von HeidiSQL anlegen (Rechtsklick auf die Verbindung / „Create New“ / „Database“; Menü „Tools“ / „User Manager“), die SQL-Skripte haben jedoch den Vorteil, reproduzierbar und wiederholt ausführbar zu sein.

    15.1.5. Die Datenbanken in diesem Dokument

    Die Kapitel 10 und 11 verwenden die folgenden Datenbanken, die sich alle auf dem lokalen MySQL-Server befinden:

    Datenbank
    Kapitel
    Erstellung
    [dbarticles]
    10

    [dbtaxes]
    10
    Skript [10-adonet/sql/dbtaxes.sql]: die Tabelle [brackets] aus Version 6 der Anwendung [Tax] und der Benutzer [admtaxes]
    [efarticles], [efshop], [efclients]
    11
    von den Programmen selbst erstellt ([EnsureCreated]) oder durch Migrationen von EF Core ([dotnet ef database update])

    Nach Abschluss der Tests kann eine Datenbank mit dem SQL-Befehl [drop database name;] im Client [mysql] oder in HeidiSQL gelöscht werden.
